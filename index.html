📖 GitHub Pages pe Publish karne ke Steps  ▼

Step 1 — GitHub Account (already hai toh skip karo)

  1. github.com → Sign up → free hai

Step 2 — New Repository banao

  1. Login → top-right + → New repository
  2. Name: cgm-leave-tracker  ·  Public select karo
  3. "Add a README file" tick karo → Create repository

Step 3 — index.html Upload karo

  1. Repository mein → Add file → Upload files
  2. index.html (jo download ki) drag & drop karo → Commit changes

Step 4 — GitHub Pages Enable karo

  1. Repository → Settings → left mein Pages
  2. Source: Deploy from a branch → Branch: main → /(root) → Save
  3. 2-3 min baad link: https://[username].github.io/cgm-leave-tracker/

Data update karna ho?

  1. Google Sheet mein naya data add karo
  2. App mein ⟳ Refresh Data click karo — automatic update ✅
